## セットアップ手順

### 前提条件

- Node.js (v14.0.0 以上)
- npm (v6.0.0 以上)

上記2点の事前インストールをお願いします

### インストール

1. リポジトリをクローンします
```bash
git clone https://github.com/yourusername/simple-crm.git
cd simple-crm
```

2. アプリケーションを起動します
```bash
npm install
```

3. ブラウザで以下のURLにアクセスします
```
http://localhost:3000
```

## 実装機能の説明

### 1.ログイン機能

- ユーザーID・パスワード入力フォーム  
- 入力バリデーション  
- エラーメッセージ表示


### 2.顧客一覧画面
- **顧客情報の一覧表示**
- **検索機能**
  - リアルタイム検索結果表示  
- **並び替え機能**
  - 名前順（昇順・降順）  
  - 登録日順（昇順・降順）  
- **レスポンシブ対応**
  - スマートフォン向けの最適化表示

### 3.デザイン
　
・わかりやすいデザインで学習コストを下げスムーズな操作を実現しました  
・柔らかい色合いで視覚的な疲れを低減します  

## 動作確認方法

### ログイン機能
　1. アプリケーションを起動すると、ログイン画面が表示されます  
　2. テスト用アカウントでログインできます  
　　　ユーザーID:admin  
　　　パスワード:pass  
　3. 入力欄が空の場合、または入力内容がテスト用アカウントと一致しない状態でログインボタンを押下するとエラーメッセージが表示されます  

###　顧客一覧画面
　1. ログイン後は顧客一覧画面に遷移、顧客一覧が表示されます  
　2. 顧客名でリアルタイム検索ができます  
　3. 「顧客名」と「登録日」の横の「↑↓」を押下するとそれぞれ昇順、降順で並び替えができます  
　4. 「ログアウト」ボタンからログアウトできます
